卡牌版本切換

同一卡名可切一般、異畫、語言、特殊印刷或其他版本，避免價格混在一起。

CardsX 官方驗證流程

所有卡牌集中由高雄總部驗證
1. 成交

每次買賣成交後，系統自動建立一組隨機且不重複的 Transaction ID。

2. 賣家寄卡

賣家依交易序號將卡牌寄至 CardsX 高雄驗證總部。

3. CardsX 驗證

驗證卡牌真偽、版本與交易標的。通過後建立唯一 CardsX ID 與 Verified 徽章。

4. 交付 / Vault

買家選擇寄送實體卡，或直接存入 CardsX Vault 繼續持有與交易。

實體交易服務

CardsX Vault

驗證後可存入 CardsX Vault，持有人可繼續掛 Ask 或接受 Bid；成交時不需要反覆寄送實體卡。
